# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Email **security@aspos.io** with:

- A description of the vulnerability
- Steps to reproduce (proof-of-concept code or a detailed description)
- The potential impact
- Your suggested fix or mitigation (optional)

You will receive an acknowledgement within **2 business days** and a resolution or status update within **14 days**.

We ask that you give us reasonable time to address the issue before any public disclosure.

## Scope

This policy covers the agent source code in this repository. Vulnerabilities in the ASPOS cloud backend (which is proprietary) should be reported to the same address.

## Supported versions

Only the latest release on `main` is actively maintained.
